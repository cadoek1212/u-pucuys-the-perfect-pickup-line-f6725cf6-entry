A program that writes one short pickup line an AI agent could say out loud: *"If I had one token left, I'd spend it saying your name."* (55 characters). The twist is the double meaning of "token" — the smallest unit a language model spends to speak, and a coin you spend on something precious.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (UTF-8, exactly the line, no trailing newline).
